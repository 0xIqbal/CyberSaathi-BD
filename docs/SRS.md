# Software Requirements Specification

## Purpose

CyberSaathi BD is a security-focused mobile application for suspicious URL analysis, document privacy scanning, Bangla health information navigation, and digital evidence organization.

## Scope

The MVP targets a Flutter mobile client and Laravel REST API for a two-student, 12-week capstone implementation.

## Primary Users

- Registered mobile users
- Administrators managing curated health content

## Functional Areas

- Authentication and user-owned data
- Suspicious URL analysis
- PDF/DOCX privacy scanning
- Curated Bangla health navigation
- Digital evidence organization

## Constraints

- LLM output must be treated as assistive, not authoritative.
- Health responses must not diagnose or prescribe.
- Evidence organization does not establish legal admissibility.
